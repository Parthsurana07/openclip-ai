# OpenClip AI 🎬

An open-source AI-powered video clipping assistant designed to help content creators discover engaging moments from video transcripts.

 🚀 Features

- Analyze video transcripts using AI.
- Identify engaging moments for short-form content.
- Generate catchy video hooks and titles.
- Suggest clip timestamps.
- Generate social media captions.

 🛠️ Tech Stack

- Python
- Streamlit
- OpenRouter API
- FFmpeg (planned)

🎯 Project Goal

Make AI-powered video content creation more accessible by providing simple, useful, and open-source tools for creators.

 📌 Project Status

Early development – building the first working version.

Contributions, suggestions, bug reports, and feature requests are welcome.
